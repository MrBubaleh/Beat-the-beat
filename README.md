# Beat the beat

Браузерный lane-based 3D-раннер: музыка задаёт темп и напряжение, трассу строит игра, не трек. Три транспорта в одном забеге — машина, конь и ракета.

## Быстрый старт

Требуется **Node.js 20+** и **npm**.

```bash
npm install
npm run dev
```

Открой в браузере адрес из терминала (обычно `http://localhost:5173`). Целевые браузеры: **Chrome** или **Edge**.

## Сборка

```bash
npm run build
npm run preview
```

Готовые файлы — в `dist/`. Встроенные треки из `video/` копируются в `dist/video/` автоматически.

## Треки

В меню — до **5 файлов** из папки `video/` (mp4, webm и др.) + кнопка **свой файл**. Повторное сжатие (опционально): `node scripts/compress-videos.mjs` (нужен ffmpeg в PATH).

## Управление

| Действие | Клавиша |
|----------|---------|
| Полосы | ← / → |
| Нитро (машина) / прыжок (конь) / вверх (ракета) | Пробел |
| Подкат / вниз | ↓ |
| Пауза | Esc |

Режим по умолчанию — **Destroy**. Доп. настройки (режим, сложность, камера) — с `?dev=1` в URL.
