================================================================
0. ЗАФИКСИРОВАННЫЕ РЕШЕНИЯ (не переоткрывать)
================================================================

Продукт:
  Destroy — лицо беты. Classic и Adrenaline в селекте до старта, без паритета polish.
  Сложность — 2–3 ярлыка над уже существующими levelgen-пресетами
  (спокойнее / обычный / мясо). Новой системы сложности нет.
  5–20 человек, ссылка / itch с паролем. Не Steam, не мобилки.
  Chrome/Edge — цель. Firefox — known-issues smoke, не ветка работ.

Картинка:
  Один купленный/скачанный low-poly kit.
  Игрок: машина, конь и ракета — все три модели, не шар/пирамида.
  Сначала AABB, потом меш в ящик.

Порядок (из опроса):
  1) Сначала Blocker честности (грузовики / late-nitro), потом арт и чужие люди.
  2) Сначала оболочка (старт, пауза, ошибки, селект), потом visual slice.
  3) Первые 3–5 чужих — только после slice с моделями, не на кубах.
  4) Режиссура calm/peak в плане обязательна, но не блокирует ссылку,
     если петля честная.
  5) Приёмка мягкая: большинство поняли, 60 FPS, known issues можно отдать.
  6) Срок короче полноты RC: резать декор, Firefox, лишние анимации.
  7) Демо-трек желателен; достаточно 3–5 треков в меню + свой файл.

Управление (факт проекта, не выдумывать):
  Машина: полосы + Space = нитро. Не «стрелка вверх».
  Габариты в этот файл не хардкодить — таблица из configs / obstacleFootprint.

================================================================
1. ЧТО ТАКОЕ БЕТА
================================================================

Тестер без разработчика:

  ссылка → трек (бандл или свой файл) → ruleset + сложность →
  понял управление → Destroy-петля с car/horse/rocket →
  понял почему проиграл → рестарт / другой трек.

Музыка режиссирует темп и напряжение, не строит трассу и не делает её нечестной.
Один скриншот = одна игра, не набор кубов.

Бета ≠ коммерческий релиз.
Бета ≠ новые механики.
Бета ≠ «любой подкаст = шедевр».

Термины (чтобы не путать «режим»):
  Транспорт — car / horse / rocket внутри забега.
  Ruleset — Destroy / Classic / Adrenaline на весь забег.

================================================================
2. ВИДЕНИЕ (GDD, не нарушать)
================================================================

  Музыка не генерирует препятствия. LevelGen автономен, isPassable — unit.
  Director — единственный источник DirectorIntent[].
  Игрок сам жмёт силу. Лучший момент = музыка + Director + действие.
  Геймплей важнее совпадения с треком и визуального шоу.
  Три транспорта уже есть. Новые не добавлять.
  Арт и оболочка усиливают доказанную петлю.

Живая игра: хочется второй забег на другом треке.
Читаемый мир: на стоп-кадре ясно что убьёт / что ломается / где бонус.

3. ГДЕ МЫ
================================================================

Есть: три транспорта и переходы; 4 полосы; поезда; рампы; нитро; комбо; HP;
Destroy дефолт (micro / жёлтый-зелёный low / tall); Classic и Adrenaline

для игрока; бандл треков; SFX-ident; GLTF; модели трёх транспортов игрока;
production-ссылка с версией.

Хвосты status.md — сначала классифицировать, fairness = Blocker до арта:
  уворот после длинных грузовиков; late-nitro; zExtent в isPassable
  только если реально ломает честность; A6/S5 — после петли, не вместо неё.

4. КРИТИЧЕСКИЙ ПУТЬ
================================================================

  0  Contract + baseline
  1  Gameplay lock (Blocker честности)     ← до арта и до чужих
  2  Footprint + читаемость на примитивах  ← бриф кита, ещё не покупка интеграции

  7  Director calm/peak (попытаться)

Параллель: после Gate 2 можно заказывать kit, пока делается фаза 3.
Интеграция мешей начинается только со slice (фаза 4).
SFX набросать с оболочкой; микс — после моделей.
A6/S5 не заменяют fairness, UX, арт.

Если срок прёт — резать в этом порядке:
  1) вторичный декор
  2) лишние анимации и VFX
  3) Firefox из цели в known-issues
  4) демо-трек (бандл 3 трека оставить)
  5) четвёртый-пятый bundled track
Нельзя резать: честность/passability; первый flow; читаемость угроз;
единый стиль кита; модели всех трёх транспортов игрока; 2–3 ярлыка сложности.

5. ПРИНЦИПЫ
================================================================

1. Одна активная фаза.
2. Нет новых крупных механик.
3. Чинить по повторяемому логу/наблюдению, не по вкусу одного человека.
4. Destroy получает juice/баланс. Classic/Adrenaline — compatibility.
5. Footprint заморожен до интеграции моделей. Меш ≤ AABB. core/ без GLTF.
6. Один kit. Не мешать стили.
7. Не рефакторить core/ и не плодить src/ui/screens/ «на чистоту».
   Оболочка поверх bootstrap/HUD.
8. Аудио: GainNode, не video.muted.
9. После первой ссылки — Blocker/P1 и JSON-калибровка, не фичи.
10. Расширение скоупа = вычеркнуть работу той же цены.

================================================================
6. РЕЖИМЫ, СЛОЖНОСТЬ, HUD
================================================================

Транспорт: машина (уворот, Space-нитро, рампы/поезда); конь (прыжок / fast-fall /
подкат); ракета (редкий бонус, топливо). Смена — в забеге, не пункт «выбери героя».

Ruleset до старта, не на лету:
  Destroy — дефолт и то, что показываешь.
  Classic — три жизни, полный smoke.
  Adrenaline — шкала, smoke; adren-update пакет не воскрешать.

Сложность: 2–3 ярлыка = существующие пресеты, которые проходят isPassable.
Пресет, который ломает проходимость, в селект не класть.

HUD: Destroy без HP. Classic/Adrenaline — свой набор, не все шкалы сразу.
Дев-пресеты gen/adren не в игровых настройках.

================================================================
7. ТЕХРАМКИ
================================================================

  core/ чистый. render/ — меши, instancing, лоадер.
  LevelGen не читает audio.
  Проходимость только unit isPassable.
  Tick: fixedUpdate 60 Hz / variableUpdate / rAF / worklet — не ломать.
  JSON + Zod + fallback.
  Цель: 60 FPS на заранее названном среднем ноуте, Chrome, типичный Destroy.
  Версия сборки в UI или в логе.
  Лицензии кита — короткий реестр.

Приёмка (мягкая, опрос):
  большинство тестеров сами начинают и отличают опасность / smash / бонус
  и три транспорта; 60 FPS «в целом держится»; known issues можно отдать
  честным списком. Нет обязательства 4/5, 95% кадров, 1000 чанков, 20 мин утечек.

Gate 0:

--------------------------------------------------------------------------------
ФАЗА 1 — Gameplay lock
--------------------------------------------------------------------------------
Только fairness. Новых механик нет.

  Закрыть Blocker: длинные грузовики / возврат в полосу; late-nitro, если врёт.
  zExtent в isPassable — только если это и есть Blocker.
  Три своих Destroy 60–90 с без «баг генератора».
  Smoke Classic и Adrenaline: старт, свой HUD, транспорты, death, restart,
  без чужих правил/монет на экране.
  typecheck / lint / test.

Не делать: A6/S5, тюнинг «чтобы кубы красивее», приглашение чужих, закупка кита.

Gate 1:
  [ ] Нет открытого Blocker честности.
  [ ] Другие ruleset стыдно не включить в селект (smoke ок, паритет не нужен).
Если gate падает — арт не начинаем.

--------------------------------------------------------------------------------
ФАЗА 2 — Footprint и читаемость
--------------------------------------------------------------------------------
  Таблица kind → смысл → w/h/d из текущего кода → цвет → силуэт.
  Язык Destroy: tall опасность; low smash-цель; micro мелочь; overhead не фура;
  ramp/train маршрут; bonus награда.
  Камера только если ряд не читается ~0.5 с.
  Стоп-кадр человеку вне проекта.
  Слоты кита: игрок car/horse/rocket; tall/low/micro/overhead; поезд; рампа;
  монета; бонусы; дорога/обочина/горизонт. Не город.

После Gate 2 — можно покупать/скачивать ОДИН kit под таблицу.
Интеграция в игру — фаза 4, не сразу все файлы в сцену.

Gate 2:
  [ ] Таблица утверждена; collision/passability зелёные.
  [ ] Стоп-кадр: опасность / ломается / бонус без внутренних имён.
  [ ] AABB после этого — только hotfix Blocker.
  [ ] Kit выбирается по слотам, не «пачка красивых машин».

--------------------------------------------------------------------------------
ФАЗА 3 — Product shell
--------------------------------------------------------------------------------
Пока kit едет — делать оболочку на примитивах (потом скин не должен ломать flow).

  Состояния: нет трека → ready → playing → paused → game over / конец трека.
  (Countdown не обязателен.)
  Старт: обещание игры; 3–5 bundled tracks; свой файл; Destroy default;
  ruleset; 2–3 сложности. Демо-автостарт — если дёшево вписывается.
  Одна короткая карточка управления, скип. Не туториал-уровень.
  Пауза. Game over: дистанция, счёт, макс. комбо, почему смерть, рестарт
  после уже существующих 2 с.
  Ошибки файла / audio context без белого экрана.
  Громкость музыка/SFX через GainNode. Файл локальный — одна фраза об этом.
  Дебаг / сырые пресеты / timeline — F1 или URL.

Не делать: выбор транспорта в меню, графические настройки, src/ui/screens/ как проект.

Gate 3:
  [ ] Новое окно → забег без голоса (пока на примитивах — ок).
  [ ] Игроку не светят raw config id.
  [ ] Пауза / конец / рестарт / смена трека и ruleset до старта стабильны.
  [ ] HUD соответствует выбранному ruleset.

--------------------------------------------------------------------------------
ФАЗА 4 — Visual slice
--------------------------------------------------------------------------------
  GLTF в render/GameScene: масштаб, pivot, пул/instancing, fallback.
  core/ не знает меши.
  Меш ≤ AABB; иначе другой ассет, не раздувать ящик.
  Slice 60–90 с: дорога, игрок-машина, ключевые угрозы Destroy, награда,
  рампа или поезд, переход в коня И в ракету хотя бы по одному разу
  (оба силуэта игрока уже модели), HUD, 2–3 SFX.
  Минимум motion: колёса / squash. Без скелета.
  Perf: 60 FPS на целевом ноуте в этом куске.

Не делать: весь город; замену всех кубов забега; второй kit.

Gate 4:
  [ ] Скриншот = один продукт.
  [ ] Конь и ракета игрока — модели.
  [ ] Нет «ударило мимо модели».
  [ ] Пайплайн повторяемый.
  [ ] Стиль принят — дальше только этот kit.

--------------------------------------------------------------------------------
ФАЗА 5 — Первый внешний тест (после slice)
--------------------------------------------------------------------------------
  3–5 человек без голосового объяснения, на shell + slice.
  1–2 контрастных трека (не речь/тишина как обязаловка).
  Логи + повторяемость. Искать: не стартует; нечестная смерть; не читает угрозы;
  не отличает транспорты; бросает в одной точке.
  «Кубы ещё где-то видны вдалеке» — P2, не Blocker, если slice читается.
  Чинить только повторяющееся.

Gate 5 (мягкий):
  [ ] Большинство сами начали и поняли цель/управление.
  [ ] Большинство отличают опасность / smash / бонус и три транспорта.
  [ ] Нет системной точки отказа у всех.
  [ ] Хотя бы часть рестартнула или сменила трек.
Если падает из-за fairness/чтения — не масштабировать арт (назад в 1–4).
Если падает из-за «мало контента вокруг slice» — это фаза 6, не провал ядра.

--------------------------------------------------------------------------------
ФАЗА 6 — Контент на забег + SFX + бандл
--------------------------------------------------------------------------------
  Остальные слоты тем же пайплайном. Сначала gameplay-critical, потом обочина.
  Три транспорта: силуэт, палитра, камера, VFX, звук — не три мира.
  SFX: tall, smash, micro, бонус, нитро, вход/выход коня и ракеты, game over.
  Не заглушать музыку игрока.
  3–5 лицензированных треков в меню; свой файл остаётся главным сценарием.
  Демо-трек — если ещё не сделан и не жрёт срок.
  Readability pass на спокойном и плотном треке.

Gate 6:
  [ ] В пользовательском пути нет случайных сырых кубов.
  [ ] Без HUD по звуку: ударил / сломал / взял бонус.
  [ ] 8–10 минут не выглядят как один зацикленный кусок
      (модульные вариации, не 40 уникальных пропов).
  [ ] VFX не прячут угрозу и не роняют 60 FPS «в целом».

--------------------------------------------------------------------------------
ФАЗА 7 — Director (попытаться)
--------------------------------------------------------------------------------
  Прогон бандла + пара своих файлов.
  Calm/peak: скорость, плотность, камера, VFX — существующие intents/множители.
  S5 beat-feel только если peak уже читается и не каша.
  Не блокирует фазу 8, если петля честная, а контраст слабый:
  тогда known issue + Later, ссылку всё равно можно отдать.

Gate 7 (мягкий, не блокер ссылки):
  [ ] Два контрастных трека ощущаются разной драматургией, не только другим цветом.
  [ ] Тестеры не списывают нечестные смерти на музыку.
  [ ] LevelGen по-прежнему автономен.

--------------------------------------------------------------------------------
ФАЗА 8 — Упаковка и ссылка
--------------------------------------------------------------------------------
  typecheck, lint, test, build; e2e только старт → забег → рестарт.
  Production: дебаг выкл, только разрешённые пресеты, версия видна.
  Chrome/Edge на целевом ноуте, 60 FPS типичного Destroy.
  itch/HTTPS, known issues, кнопка лога на game over (рекордер уже есть).
  Rollback — если дёшево (статический хостинг + предыдущий dist); не раздувать ops.
  Волна A: те же 3–5 или чуть шире. Патч: Blocker/P1 + JSON, не фичи.
  Волна B — только если волна A не развалилась; иначе один cycle и стоп.

Gate 8:
  [ ] Ссылка открывается, дебаг не на лице.
  [ ] Нет открытого Blocker (P1 по возможности; остаток — known issues).
  [ ] Сам прошёл с нуля: новое окно → трек → ruleset/сложность → смерть → рестарт.

Успех беты (мягкий):
  играют без индивидуальной техпомощи; смерти в основном честные;
  три транспорта различимы; часть людей рестартит / меняет трек;
  после волны список — polish, не ядро.
  «Музыка режиссирует» — желаемый исход, не обязательный провал беты.

11. ФИДБЕК (короткий)
================================================================

1. Что было целью и что ты пытался делать?
2. Что било, что ломалось, что было наградой?
3. Чем отличались машина, конь, ракета?
4. Музыка что-то меняла или просто фон?
5. Где стало скучно, нечестно или непонятно? Ruleset/сложность ясны?

Приоритет: Blocker (нельзя играть) → P1 (нечестно / сломан flow / не читается)
→ P2 feel → Later.

Лог: build id, трек, ruleset, смерти, переходы транспорта — насколько уже
даёт PlaytestRecorder, без новой платформы аналитики.

12. ВРЕМЯ (ориентир, не контракт)

Документы: status.md = какая фаза/гейт; changelog = что сделали; этот файл = карта.

================================================================
13. СЕЙЧАС НЕ ДЕЛАТЬ, ПОКА НЕТ УКАЗАНИЯ
================================================================

План принят как карта. Код, закупка кита и приглашение тестеров — только
