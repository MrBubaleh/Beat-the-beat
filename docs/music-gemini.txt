# Музыкальный и процедурный SFX-движок (Web Audio) для Music Director Runner
Автор предложения: Gemini / AI Agent
Дата: 2026-09-03
Статус: Согласовано, Фаза 1 в реализации

---

## 1. Введение и цели

Music Director Runner — музыкальный раннер, где аудио-дорожка (видеотрек) является центральным драматургическим стержнем. Уже реализована система реактивной обработки музыки (ActiveDirector, Damage EQ, Nitro Highshelf, Rocket Muffle, Tutorial Slow-Mo).

Главная цель SFX-системы:
Добавить богатую, динамичную и тактильную звуковую обратную связь (удары, разрушения, сбор предметов, ощущение скорости и способностей) **без готовых аудиофайлов (WAV/MP3)** на первом этапе, используя синтез Web Audio API. При этом SFX работают в синергии с музыкой, не засоряют частотный спектр (anti-mud) и не перегружают процессор.

---

## 2. Утверждённые решения (2026-09-03)

По итогам опроса пользователя зафиксированы следующие параметры:
1. **Баланс громкости**: `delicate_support` — деликатный тактильный слой; музыка остаётся доминирующей на 1-м плане, SFX сведены на уровне -6..-8 dB.
2. **Стилистика синтеза**: `hybrid_deep` — глубокий гибрид: плотный саб-бас, фильтрованный шум, киберпанк/аркадная эстетика без навязчивого высокочастотного писка.
3. **Звук сбора монет**: `pitch_ladder` — ступенчатое повышение тона при непрерывном сборе до 1 октавы (Subway Surfers style).
4. **Дакинг музыки**: `soft_ducking` — мягкое кратковременное приседание музыки (-3..-4 dB на 150–250 мс) при тяжёлом ударе (Hit) для кинематографического веса столкновения.
5. **Двигатель машины**: `acceleration_only` — ветер звучит непрерывно от скорости, а рокот двигателя подключается при разгоне, дрифте и нитро, освобождая бас для музыки в крейсерском режиме.
6. **Способности (Нитро/Ракета)**: `punchy_burst_and_hum` — яркий стартовый импульс + умеренный свист турбины/сопла поверх эквалайзера музыки.

## 3. Архитектура и поток данных

В соответствии с правилами проекта (`.cursor/rules/music-director-runner.mdc` и `docs/architecture.md`):
- `src/core/` — чистый TS без Three.js, DOM, Web Audio API.
- Вся логика очередей, кулдаунов, приоритетов, лимитов голосов и расчёта высоты тона (pitch ladder) находится в `src/core/sfx/` и покрывается детерминированными unit-тестами.
- Рантайм-синтез (узлы Web Audio, генерация шума, модуляция частоты/гейна) находится в `src/audio/sfx/`.

### Схема потока данных

```
+--------------------------------------------------------------+
|                          src/core/                           |
|                                                              |
|   GameSim (hit, coins, micro, smash, abilities, landing)    |
|                              |                               |
|                              v (SfxEvent)                    |
|                        SfxDirector                           |
|      - Cooldown & debounce per event type                    |
|      - Voice limit & priority arbitration                    |
|      - Pitch ladder calculations (coins / combo)             |
|      - Parameter calculation (gain/pitch vs speed/damage)    |
+------------------------------+-------------------------------+
                               |
                               | SfxCommand[]
                               v
+--------------------------------------------------------------+
|                          src/audio/                          |
|                                                              |
|                         SfxEngine                            |
|       - Voice Pool Manager (pre-allocated synths)            |
|       - Continuous Generators (Wind, Engine loop)            |

|                              |                               |

|                              v                               |

|                              |                               |
|                              v                               |
|                  master (DynamicsCompressor)                 |
+--------------------------------------------------------------+
```

## 4. Архитектура шин (Audio Graph Sub-Buses)

В `AudioGraph.ts` в существующий `sfxBus` добавляются тематические подшины со своими гейнами и фильтрами для раздельного контроля громкости и динамического дакинга:

```
                  +--- impactBus (GainNode) -----+
                  |                              |
                  +--- pickupBus (GainNode) -----+
                  |                              |
[SfxEngine Voices] --- engineBus (GainNode) -----+---> sfxBus ---> master ---> ctx.destination
                  |                              |
                  +--- abilityBus (GainNode) ----+
                  |                              |
                  +--- uiBus (GainNode) ---------+
```

### Назначение шин:
1. **impactBus**: Столкновения (hit), разрушения (smash), приземления (landing). Самый высокий приоритет. При срабатывании кратковременно приглушает (ducking) `pickupBus` и `engineBus`.
2. **pickupBus**: Монеты, micro green. Высокая плотность событий, ограниченный суммарный гейн, чтобы пачки монет не вызывали клиппинг.
3. **engineBus**: Непрерывные процедурные петли: шум ветра (wind) и рокот мотора (car) / цокот копыт (horse) / гул дюз (rocket).
4. **abilityBus**: Звуки включения, горения и завершения Нитро и Ракеты.
5. **uiBus**: Смена режимов, комбо-страйки, предупреждения, game over.

## 5. Голосовой пул, приоритеты и Voice Limiting

Чтобы избежать перегрузки Web Audio API, щелчков и высокого CPU:
1. **Пул голосов**: Фиксированный пул одноразовых генераторов (One-Shot Voice Nodes) — максимум 10–12 одновременно звучащих процедурных голосов.
2. **Приоритеты (Voice Priority)**:
   - `Priority 1 (Critical)`: Игровой урон / Столкновение (Hit), Game Over, Активация Нитро/Ракеты.
   - `Priority 2 (High)`: Medium Smash (разрушение препятствия), Приземление (Landing).
   - `Priority 3 (Medium)`: Смена полосы (Lane switch), Near-miss, Подкат коня.
   - `Priority 4 (Normal)`: Монеты (Coins), Micro green break.
   - `Priority 5 (Ambient)`: Фоновые свисты и щелчки.
3. **Правила вытеснения (Voice Stealing)**:
   - Если свободных голосов нет, запрос с более высоким приоритетом мгновенно гасит (с 5 мс fade-out) самый старый голос с более низким приоритетом.
   - Запросы с равным или более низким приоритетом отбрасываются либо перезапускают существующий инстанс (voice re-trigger).
4. **Кулдауны (Cooldowns) & Дебаунс**:
   - `hit`: 120 мс
   - `smash`: 70 мс
   - `micro green`: 40 мс
   - `coin`: 35 мс (со ступенчатым повышением тона)
   - `lane switch`: 120 мс
   - `near-miss`: 150 мс

## 6. Процедурные рецепты синтеза звуков (Web Audio Patches)

Все звуки синтезируются в реальном времени из базовых примитивов:
`OscillatorNode` (sine, triangle, sawtooth, square) + `AudioBufferSourceNode` (белый/розовый зацикленный буфер шума) + `BiquadFilterNode` (lowpass, highpass, bandpass, notch) + `GainNode` (ADSR-огибающие).

### 6.1. Столкновение с уроном (Hit / Impact)
- **Концепция**: Тяжёлый кинетический удар с резким щелчком (transient click), быстрым саб-дропом (sub drop) и затухающим шумовым хвостом.
- **Синтез**:
  - Осциллятор 1: `triangle`, питч стремительно падает со 180 Гц до 35 Гц за 110 мс (`exponentialRampToValueAtTime`).
  - Генератор шума: импульс белого шума через bandpass (400–800 Гц) с огибающей атаки 1 мс и спада 80 мс.
  - Модуляция от тяжести: при критическом уроне (`critical`) добавляется суб-басовый синус 45 Гц с более длинным хвостом (250 мс) и дисторшн через `WaveShaperNode`.

### 6.2. Разрушение препятствия нитро (Medium Green Smash)
- **Концепция**: Хрустящий, сочный взрыв преграды («разлёт осколков + кинетический толчок»).
- **Синтез**:
  - Слой 1: Шумовой всплеск через sweep bandpass (от 3.5 кГц до 400 Гц за 120 мс).
  - Слой 2: Синусоидальный питч-дроп со 120 Гц до 45 Гц (ощущение массы и пробития).
  - Длительность: 150 мс.

### 6.3. Подбор Micro Green
- **Концепция**: Короткий упругий «поп / клик» с позитивным стеклянным резонансом.
- **Синтез**:
  - Осциллятор: `sine` с частотой 800–1200 Гц, быстрая огибающая (атака 2 мс, decay 45 мс).
  - Дополнительный резонансный фильтр (Q=6..8) для ощущения кристалла/светящейся сферы.

### 6.4. Монеты (Coins) и Pitch Ladder
- **Концепция**: Фирменный аркадный сбор. При сборе дорожки из монет каждая следующая звучит на полтона-тон выше, создавая музыкальную фразу.
- **Синтез**:
  - Осциллятор: два параллельных `sine` в чистую квинту или терцию (например, 1046 Гц + 1318 Гц — C6/E6), создающие чистый колокольчиковый тембр.
  - Огибающая: мгновенная атака (1 мс), спад экспоненциальный 70 мс.
  - Pitch Ladder: при интервале между монетами < 350 мс счётчик ноты растёт от 0 до 8 (до 1 октавы вверх), при паузе > 350 мс возвращается на базу.

### 6.5. Шум ветра от скорости (Wind Loop — Continuous)
- **Концепция**: Фоновый аэродинамический поток, усиливающий ощущение безумной скорости.
- **Синтез**:
  - Зацикленный буфер белого шума через `BiquadFilterNode` (lowpass + bandpass).
  - Частота среза фильтра динамически интерполируется: при скорости 10 м/с -> 400 Гц; при 28 м/с -> 2200 Гц.
  - Гейн: от почти неслышного (0.02) на базовой скорости до плотного свиста (0.22) на турбо/нитро.

### 6.6. Двигатель машины (Engine Loop — Continuous)
- **Концепция**: Упругий механический бас, реагирующий на ускорение и нитро.
- **Синтез**:
  - Осциллятор с богатыми гармониками (`sawtooth` с lowpass фильтром) + суб-осциллятор (`triangle` октавой ниже).
  - Подключается и раскрывается при ускорении/нитро, не конфликтуя с басом трека при равномерном ходе.

### 6.7. Нитро (Nitro: Trigger, Loop, Release)
- **Концепция**: Мощный реактивный подхват, работающий в унисон с уже существующим `nitroShelf` музыки.
- **Синтез**:
  - Trigger: Резкий восходящий sweep синуса (150 -> 600 Гц) + шум струи.
  - Loop: Высокочастотное шипение турбины + резонансный гул.
  - Release: Сброс давления (blow-off valve) — короткий нисходящий шумовой выдох (100 мс).

### 6.8. Режим ракеты (Rocket)
- **Концепция**: Глубокий рокот стартующего челнока и космический вакуумный полет.
- **Синтез**:
  - Launch: Мощный низкочастотный рокот (pink noise + 40 Гц rumble) с нарастанием.
  - Cruise: Низкочастотный вибрирующий бас с мягким фильтром.

## 7. Anti-Mud и стратегия сведения с музыкой (Ducking & EQ)

1. **Частотное разделение**:
   - Музыка уже подвергается динамической фильтрации в `AudioGraph.ts` (Damage Lowpass, Rocket Muffle, Nitro Highshelf).
   - SFX-звуки попадают в спектральные окна, освобождаемые фильтрами музыки.
2. **SFX Ducking**:
   - При срабатывании громкого `Hit` или `Smash` подшины `pickupBus` и `engineBus` приседают на -4..-6 dB на 150–250 мс.
3. **Music Ducking (утверждено `soft_ducking`)**:
   - Кратковременное (на 150–250 мс) мягкое приседание музыки на -3..-4 dB в момент сильного столкновения (`Hit`), создающее кинематографический вес удара.

## 9. Этапы реализации (Roadmap)

### Фаза 1: Инфраструктура + Первые звуки (MVP Core) — ТЕКУЩИЙ ЭТАП
1. Создание `configs/sfx.default.json`, Zod-схемы в `src/core/config/schemas.ts` и `fallbacks.ts`.
2. Архитектура шин в `AudioGraph.ts` (подшины `impactBus`, `pickupBus`, `engineBus`, `abilityBus`, `uiBus` + soft music ducking).
3. Класс `SfxDirector` в `src/core/sfx/` (очереди, дебаунс, приоритеты, pitch ladder, unit-тесты без Web Audio).
4. Класс `SfxEngine` в `src/audio/sfx/` (пул голосов, генераторы звуков).
5. Тестовая интеграция в `bootstrap.ts` и `GameSim.ts`:
   - Звук подбора монеты (`coin` с pitch ladder).
   - Звук столкновения (`hit`).
   - Проверка: `typecheck`, `lint`, `unit tests`.

### Фаза 2: Непрерывные звуки движения (Continuous Loops)
1. Реализация процедурного генератора ветра (`WindVoice`): шум + фильтр от скорости.
2. Реализация процедурного генератора двигателя машины (`EngineVoice`): обороты от скорости и ускорения.

### Фаза 3: Импакты и разрушения (Tactile Juice)
1. Реализация `micro green break` (звонкий поп/клик).
2. Реализация `medium green smash` (кинетический удар + хруст разлёта).
3. Приземление машины (`metal thud`).

### Фаза 4: Способности и Режимы (Abilities & Modes)
1. Нитро: цикл активации (burst), петли горения и выхода.
2. Ракета: рев стартовых ускорителей, фоновый гул полета.
3. Конь: прыжок, цокот, подкат (slide), мягкое приземление.

### Фаза 5: Полировка, тонкий тюнинг и Anti-Mud
1. Lane switch whoosh (со стерео-панорамированием влево/вправо).
2. Near-miss swoosh.
3. Тонкий баланс уровней громкости с музыкальным треком, тюнинг дакинга и компрессии.
