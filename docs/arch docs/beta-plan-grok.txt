BETA PLAN v2 — Music Director Runner
Дата: 2026-08-28
Автор: Grok. Не заменяет GDD / architecture / update1-design.
Статус: решения зафиксированы. Черновик `docs/beta-plan-grok.txt` не использовать.

Предыдущий файл был картой с допущениями. Этот — рабочая карта беты.

================================================================
ЗАФИКСИРОВАНО
================================================================

1. Бета = срез для 5–20 человек по ссылке / itch. Не Steam, не мобилки,
   не «хочется купить». Человек играет без тебя за плечом.

2. Destroy — дефолт, лицо беты. Classic и Adrenaline не выкидываем:
   в оболочке будет выбор режима и, скорее всего, сложности.
   Это не три равных продукта: бюджет полировки почти весь на Destroy.

3. Картинка до беты: простые купленные / скачанные модели (low-poly kit).
   Не свой пайплайн персонажей, не микс пяти стилей, не AAA.
   Сначала заморозка габаритов, потом покупка под ящики — иначе два раза платить.

================================================================
ЧТО ТАКОЕ ЭТА БЕТА
================================================================

Чужой человек открывает ссылку и за 30 секунд понимает петлю:

  выбрать трек (+ режим / сложность) → ехать → ломать / уворачиваться →
  конь / ракета как смена языка → смерть → рестарт.

Мир читается силуэтом и цветом, уже не «куб = грузовик».
Музыка не строит трассу, но с треком хочется перезапустить.
Дебаг не на лице экрана.

Не цель беты: любой подкаст = шедевр, коммерческий арт, мета-прогресс.

================================================================
ГДЕ МЫ
================================================================

Есть: три транспорта, 4 полосы, поезда, рампы, нитро, комбо, HP,
Destroy как дефолтные правила, Director / LevelGen / конфиги, juice,
debug / replay / playtest-лог.

Нет как у продукта: оболочка старта, селектор режима/сложности для игрока
(сейчас это дев-контролы), бандл треков, SFX-ident, модели, пайплайн GLTF.

Хвосты feel (грузовики / compaction, late-nitro, A6, S5) — чинить только
если ломают петлю. Не открывать новые системы.

================================================================
КАК НЕ СЛИТЬ ВРЕМЯ
================================================================

Порядок:

  заморозка габаритов → читаемость на примитивах → оболочка с селектором →
  SFX + 3–5 треков → купленные меши в те же ящики → режиссура на бандле →
  ссылка людям.

Правила:
  — Одна фаза в работе. Идея из другой фазы → в этот файл / status, не в код.
  — Destroy получает новый juice / баланс первым. Classic и Adrenaline:
    не падают, селектор честный, HUD не врёт. Паритет эффектов не делать.
  — Сложность = ярлыки над уже существующими levelgen-пресетами.
    Не четвёртый ruleset и не новая экономика.
  — Меш живёт в render/. Ядро не знает про GLTF. AABB не раздувать «под модель».
  — Playtest в конце подэтапа: 60–90 с, 3–5 буллетов.

Ловушки: вечный feel-pass; купить модели до таблицы размеров;
полировать три режима как три игры.

КАРТА ФАЗ
================================================================

  0  Продукт словами           без кода
  1  Gameplay lock             петля Destroy + «другие режимы не сломаны»
  2  Читаемость                примитивы, язык угроз, таблица footprint
  3  Оболочка                  старт, пауза, конец, режим, сложность
  4  Звук                      SFX + бандл треков
  5  Купленные модели          скин, не новый геймплей
  6  Режиссура                 calm/peak на бандле
  7  Отдать                    билд, инструкция, known issues

Жёстко: 0 → 1 → 2, затем покупка арта (к 5).
3 и 4 можно после 1, параллельно с заказом моделей (если таблица 2 уже есть).
5 не начинать, пока 2 не закрыта: иначе kit не того масштаба.
6 не вместо 1–5. 7 — ворота.

================================================================
ФАЗА 0 — ПРОДУКТ СЛОВАМИ
================================================================

  0.1  Этот файл — источник «что бета». Не переоткрывать Destroy vs Classic.
  0.2  Одна страница для игрока: управление, Destroy в 5 строках,
       что делают конь и ракета, что выбирается в меню.
  0.3  Ярлыки селектора (решить до фазы 3, не в коде сейчас):
         Режим:     Destroy / Classic / Adrenaline
                    (внутренние id как сейчас, снаружи — понятные имена).
         Сложность: 2 или 3 пункта, каждый = уже существующий levelgen preset.
                    Если не ясно, какие три — в бете можно временно
                    «режим + один дефолтный пресет», сложность докинуть.
  0.4  Текущий playtest-хвост: либо в фазу 1 списком, либо «живём с этим».

Выход: можно объяснить бету за минуту. Селектор назван, не спроектирован заново.

================================================================
ФАЗА 1 — GAMEPLAY LOCK
================================================================

Новых механик нет. Только дыры петли.

  1.1  Destroy, 60–90 с: плотность micro / medium / tall, smash иногда.
  1.2  Баги честности: удар в пустоту, стенка без выхода, длинный объект.
  1.3  Конь / ракета: только если переход врёт скорость или убивает незаслуженно.
  1.4  Classic и Adrenaline: один прогон каждый. Старт, смерть, рестарт,
       смена режима не оставляют чужой HUD / чужие монеты. Не баланс «как Destroy».
  1.5  Заморозка footprint: kind → ширина / высота / глубина / смысл цвета.
       После этого габариты — только hotfix. По этой таблице покупать арт.

Выход: три забега Destroy без «это баг генератора». Другие режимы не стыдно
включить в селекте.

================================================================
ФАЗА 2 — ЧИТАЕМОСТЬ (ещё можно без купленных мешей)
================================================================

Нужна и как playtest, и как бриф магазину ассетов.

  2.1  Язык Destroy:
         tall      смерть/урон     высокий, длинный, красный
         low       жёлтый→зелёный  легковая, smash когда можно
         micro     всегда ломается мельче, не монета
         overhead  арка            не грузовик
         рампа/поезд               «наедь сюда»
         бонусы                    уже шар / пирамида — усилить контраст
  2.2  Посадка на полосу, камера только если ряд не читается.
  2.3  Убрать визуальный шум прототипа с «игрового» вида (дебаг → флаг).
  2.4  Стоп-кадр другу: путает low и tall → не заказывать модели.

Выход: таблица размеров + понятный стоп-кадр. Можно идти в магазин кита.

================================================================
ФАЗА 3 — ОБОЛОЧКА
================================================================

Минимум продукта, не GDD §20 целиком.

  3.1  Состояния: нет трека → ready → playing → paused → game over.
  3.2  Выбор трека: файл и/или бандл (бандл можно добрать в фазе 4).
  3.3  Выбор режима (Destroy по умолчанию) и сложности, если ярлыки из 0.3 готовы.
       Смена — до старта забега, не на лету посреди трассы.
  3.4  Пауза, рестарт после задержки game over.
  3.5  HUD по режиму: в Destroy без HP; Classic/Adrenaline — свой честный набор,
       без трёх шкал сразу «на всякий случай».
  3.6  Дебаг и сырые пресеты — F1 / URL, не лицо беты.

Не делать: обучение на 5 экранов, графические настройки, выбор транспорта
в меню, лидерборд, сейв мета-прогресса.

Выход: инструкция = ссылка, трек, режим, стрелки + Space.

================================================================
ФАЗА 4 — ЗВУК
================================================================

  4.1  Короткий набор SFX: tall, smash, micro, бонус, конь/ракета вход-выход,
       game over. Громкости в конфиге.
  4.2  3–5 треков разного характера в бандле. Не обязательство «любой эмбиент».
  4.3  По-прежнему только GainNode, не video.muted.

Выход: без HUD по звуку понятно ударил / сломал / взял бонус.

================================================================
ФАЗА 5 — КУПЛЕННЫЕ / СКАЧАННЫЕ МОДЕЛИ
================================================================

На критическом пути этой беты. Простые, один стиль, под таблицу фазы 2.

  5.1  Слоты (не больше): машина игрока, low, tall, micro, overhead,
       поезд, рампа, монета, бонус коня, бонус ракеты.
       Игрок-конь / игрок-ракета: простой меш или временно шар/пирамида,
       если в ките нет вменяемого аналога.
  5.2  Один kit. Не смешивать Kenney + sci-fi + реалистичные фуры.
       Масштаб в метрах ≈ игровые ящики. Лишнее в паке отбрасывать.
  5.3  Пайплайн: GLTF → пул в render/. core/ без Three/GLTF.
  5.4  Меш ≤ AABB. Не влезает — режем меш или берём другой ассет.
  5.5  Движение минимум: колёса / squash smash. Без скелетных катсцен.
  5.6  Мир: дорога, обочина, горизонт (видео уже есть). Не город.

Покупка после 1.5 + 2, не «пока механика качается, закажу пачку машин».

Выход: коллизионные тесты зелёные; playtest не «ударило мимо модели».

================================================================
ФАЗА 6 — РЕЖИССУРА НА БАНДЛЕ
================================================================

  6.1  Контраст calm/peak (бывший A6): скорость, плотность, VFX, камера.
       Без новых сущностей.
  6.2  Beat-feel (S5) только если 6.1 не каша.
  6.3  Прогон на 3–5 треках фазы 4. Множители, не ноты-препятствия.

Выход: два разных трека = два разных забега, трасса честная.

================================================================
КАК РЕЖИМЫ И СЛОЖНОСТЬ НЕ СОЖРУТ БЕТУ
================================================================

Селектор — продукт. Три полных баланса — нет.

  Destroy     = то, что ты показываешь и на чём режешь feel.
  Classic     = «классические 3 жизни», должен запускаться.
  Adrenaline  = «шкала», должен запускаться; пакет adren-update не воскрешать.

Сложность не придумывать с нуля: подписать 2–3 текущих пресета
(спокойнее / обычный / мясо). Preset, который ломает проходимость,
в селект не класть.

Любой новый VFX/HUD: сначала Destroy, потом решить, виден ли он в других.
Если сомнение — только Destroy.
