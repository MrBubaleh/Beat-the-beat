# Adren Update — план доработок (juice + обучение нитро)

> Статус: **⏸ на паузе** (активен Destroy update).  
> Связанный контекст: `docs/adrenaline-gameplay.txt`, `docs/destroy-update.md`.

## Цель пакета

Сделать **читаемый язык риска и награды** вокруг нитро и HP: игрок заранее видит возможности (трещины, контур, монеты), понимает ошибку (красная вспышка, искры) и получает позитивный отклик за правильное действие (зелёная энергия, вспышки шкал). Часть фич — **оба режима** (Classic + Adrenaline), часть — только машина/нитро.

## Волны и порядок

Принцип: сначала **визуальный алфавит** (объекты → HUD/дорога → персонаж), потом **геймплей levelgen**, в конце **сложный coin-funnel**. После каждой волны с VFX — **короткий playtest** (60 с, запись экрана).

```
Волна 1 ──► playtest ──► Волна 2 ──► Волна 3 ──► playtest ──► Волна 4 ──► playtest ──► Волна 5 ──► playtest ──► Волна 6
  O1–O3                      H1–H2, R1              P1–P5                    T1                      O4                    C1–C2
```

### Волна 5 — Recovery-маршрут (геймплей)

| ID | Суть |
|----|------|
| O4 | Условие: HP низкий (ADREN visual &lt; порога **или** Classic damaged+) **и** `nitroCharge == 0` → **−плотность + чаще safeGuide**, без nitro-challenge на окно ~8 с | **Решение:** density + safeGuide |

**Не путать** с `nitroReady` (сейчас даёт **сложные** nitro-challenges). O4 — обратный сигнал: **спасение**.

**Реализация:** флаг в `GameSim` → `LevelGenerator` modifiers (как `setNitroReady`, но `setRecoveryMode`).

**Playtest:** не делает забег тривиальным; срабатывает только в «двойной яме» (нет HP и нет нитро).

---

### Волна 6 — Монеты «сквозь low» (обучение + comeback)

| ID | Суть |
|----|------|
| C1 | Если нитро full ≥ **2.5 с** **и** (ADREN visual &lt; **45%** **или** Classic damaged+) → spawn монет в low + линия за ним | оба режима |
| C2 | **Первый** full nitro за забег — обязательный триггер; дальше — «часто, но не каждый раз» | оба режима |

**Зависит от:** O1 (игрок должен понимать, что low разрушаем), волны 1–3 желательно приняты.

**Реализация:** таймер `nitroFullSince` в `GameSim`, счётчик `nitroTutorialUsed`, динамический spawn монет + low (аналог `spawnMusicCoinPath` / turbo scene). **Не** ломать проходимость — unit `isPassable` на сгенерированный коридор.

**Playtest:** обязательный первый кейс не мешает опытным; коридор не ведёт в стену; работает на разных пресетах levelgen.

**Конфиг (черновик):** `adrenaline.nitroCoinFunnel` или `game.nitroSmashGuide` — `fullSeconds`, `adrenBelowPercent`, `repeatChance`, `leadRows`.
