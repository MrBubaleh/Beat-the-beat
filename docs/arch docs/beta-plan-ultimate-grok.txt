BETA PLAN ULTIMATE — Music Director Runner
Дата: 2026-08-28
Автор сборки: Grok. Источники: gemini / gpt / grok / muse — взяты сильные куски, слабые отброшены.
Не заменяет GDD (about v2), architecture.md, update1-design.md.

Как пользоваться: одна активная фаза. Детализировать только её.
Новая идея не из текущей фазы → Later. Добавить в бету можно только обменом:
что-то равное по стоимости вычеркнуть.

================================================================
1. ЧТО ТАКОЕ ЭТА БЕТА (зафиксировано)
================================================================

Закрытый вертикальный срез для 5–20 человек по ссылке / itch (пароль).
Desktop Chrome/Edge. Firefox — smoke, не отдельная ветка. Не Steam, не мобилки.

Тестер без инструктора за плечом:
  открыл ссылку → выбрал трек (бандл или свой файл) → при желании сменил
  режим/сложность → понял управление → проехал забег на машине с конём и/или
  ракетой → понял почему проиграл → рестарт. Музыка заметно режиссирует,
  но не делает трассу нечестной. Мир — один low-poly kit, не кубы.

Destroy — лицо и почти весь бюджет feel.
Classic и Adrenaline — в селекте до старта забега, должны запускаться.
Паритет juice не делать.

Картинка: простые купленные/скачанные модели, один стиль.
Сначала ящики коллизии, потом меш в ящик. Не наоборот.

Бета ≠ коммерческий релиз (этап 6 GDD).
Бета ≠ «ещё пакет механик».
Бета ≠ «любой подкаст = шедевр» (это длинный этап 5 GDD, не этот документ).

================================================================
2. ВИДЕНИЕ ПРОДУКТА (не нарушать)
================================================================

Из GDD, иначе это уже другая игра:

  — Музыка не генерирует препятствия. LevelGen автономен.
  — Музыка — режиссёр: спокойно / рост / пик / спад. Director — единственный
    источник режиссёрских решений.
  — Игрок сам жмёт способность. Лучший момент = музыка + Director + действие.
  — Геймплей важнее музыки: нечестное требование музыки игнорируется.
  — Три языка транспорта уже есть: машина, конь, ракета. Новые не добавлять.
  — Арт и оболочка усиливают доказанную петлю, не заменяют её проверку.

Критерий «игра жива»: хочется второй забег на другом треке.
Критерий «картинка готова»: на стоп-кадре ясно что убьёт / что ломается / где бонус.

================================================================
3. ГДЕ МЫ СЕЙЧАС
================================================================

Есть и не переоткрывать как фичи:
  три транспорта и переходы; 4 полосы; поезда; рампы; нитро (у машины — Space);
  комбо; HP; Destroy как дефолтные правила (micro / жёлтый-зелёный low / tall);
  Classic и Adrenaline в дев-селекте; Director + MusicState + LevelGen;
  JSON-конфиги и hot-reload; juice (near-miss, smash, horizon…);
  HUD / задержка game over 2 с; PlaytestRecorder, replay, debug overlay;
  unit ~325+, typecheck/lint/e2e smoke.

Нет как у продукта:
  старт без дебаг-панели на лице; бандл треков + демо-трек;
  селектор режима/сложности для игрока; SFX-ident; GLTF-пайплайн;
  production-деплой с версией.

Открытые хвосты (status.md) — не новые системы:
  late-nitro трафик; длинные грузовики / compaction / zExtent в isPassable;
  A6 calm/peak и S5 beat-feel — после того как петля честная.

Не выдумывать: нитро не «стрелка вверх»; не хардкодить габариты в этот файл
(они живут в configs + obstacleFootprint и ещё недавно менялись).

================================================================
4. СТРАТЕГИЯ (почему такой порядок)
================================================================

Путь:

  заморозить скоуп и footprint
  → закрыть дыры петли (только Blocker)
  → дешёвый blind-тест на ТЕКУЩЕЙ картинке (дни, не недели)
  → язык читаемости на примитивах = бриф магазину
  → один visual slice 60–90 с (kit + пайплайн + perf)
  → оболочка продукта
  → остальные модели тем же пайплайном
  → SFX + бандл + контраст Director
  → hardening / деплой
  → две волны тестеров, патч только JSON + Blocker

Почему не «сразу купить пак» (muse/gemini next-step):
  габариты ещё живые; без slice легко купить не тот масштаб и стиль.

Почему не «сначала 9 недель кубов» (перегиб gpt):
  восприятие скорости меняется после моделей; вечный тюнинг на боксах — ловушка.
  Blind-тест нужен короткий: ищем нечестные смерти и «музыка ничего не делает»,
  а не оценку красоты.

Почему slice до массовой замены (gpt):
  один фрагмент проверяет стиль, читаемость, импорт, FPS. Потом копируем приём.

Правило арта: footprint заморожен → меш ≤ AABB → core/ не знает GLTF.
Правило режимов: новый VFX/HUD сначала Destroy; в остальные — только если
  без этого селект врёт.
Правило сложности: ярлыки над уже существующими levelgen-пресетами,
  не четвёртый ruleset.

================================================================
6. РЕЖИМЫ И СЛОЖНОСТЬ
================================================================

Транспорт (уже в забеге, не пункт меню):
  машина — уворот, нитро Space, рампы/поезда;
  конь — прыжок / fast-fall / подкат;
  ракета — редкий бонус, топливо, сбор.

Правила (селект до старта, не на лету):
  Destroy     — дефолт, то что показываешь;
  Classic     — три жизни, должен стартануть / умереть / рестартнуть;
  Adrenaline  — шкала, то же; пакет adren-update не воскрешать.

Сложность (0–3 ярлыка, решить в фазе 0):
  каждый ярлык = существующий levelgen preset, который проходит isPassable.
  Нет внятных трёх — в бете честно один пресет Destroy, сложность не выдумывать.

HUD:
  Destroy — без HP, нитро/комбо/счёт как язык игры.
  Classic / Adrenaline — свой честный набор, не три шкалы «на всякий случай».
  Дев-пресеты gen/adren — не в игровых настройках.

================================================================
7. ТЕХНИЧЕСКИЕ РАМКИ
================================================================

  core/ чистый, без Three/DOM/GLTF.
  render/ — единственный слой моделей и instancing.
  LevelGen не читает audio; Director — единственный источник DirectorIntent[].
  Аудиопоток: GainNode, не video.muted.
  Проходимость: unit isPassable, без рантайм-чекера.
  Tick: fixedUpdate 60 Hz / variableUpdate / rAF / worklet — не ломать.
  Конфиг: JSON + Zod + fallback; невалидное не роняет игру.
  Ассеты: один kit, метры ≈ игровые ящики, лицензии в короткий реестр.
  Цель кадра: 60 FPS на заранее названном среднем ноуте, Chrome.
  Версия сборки на экране/в логе, чтобы отзыв привязать к билду.
